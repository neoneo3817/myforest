# 나만의 숲 웹앱 (GitHub Pages)

## 저장소에 넣을 파일

아래 항목을 저장소 최상위 폴더에 그대로 복사하세요.

- `index.html` (현재 약 85MB)
- `manifest.webmanifest`
- `service-worker.js`
- `icons` 폴더 (192px, 512px 앱 아이콘)

GitHub Desktop에서 변경 파일을 커밋한 뒤 `Push origin`을 누르면 Pages가 갱신됩니다.

## Pages 설정

저장소 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다. 무료 요금제에서는 저장소가 공개여야 합니다.

## 휴대폰 설치

Android Chrome에서 배포 주소를 새로고침한 뒤 ⋮ 메뉴의 `앱 설치`를 선택합니다. 새 설정이 반영되기 전까지 잠시 기다리거나 Chrome에서 페이지를 다시 열어 주세요. 이전에 추가한 홈 화면 바로가기가 있다면 먼저 지운 뒤 설치 메뉴를 확인하세요.

## 참고

- 3D 모델은 HTML 파일 안에 포함되어 있습니다.
- 3D 엔진과 일부 글꼴을 불러오려면 인터넷이 필요합니다.
- 서비스 워커는 앱 설치 지원용으로 네트워크 요청을 전달합니다. 큰 HTML을 캐시하지 않으므로 완전한 오프라인 실행은 지원하지 않습니다.
- 카드 기록과 숲 배치는 현재 사용 중인 브라우저에 저장됩니다. 다른 기기와 자동으로 동기화되지 않습니다.
- 공개 저장소에서는 HTML 코드와 3D 모델을 누구나 볼 수 있습니다.

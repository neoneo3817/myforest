# 나만의 숲 웹앱 (GitHub Pages)

## 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. GitHub Desktop으로 저장소를 컴퓨터에 복제합니다.
3. 이 폴더 안의 `index.html`을 저장소 폴더에 복사합니다.
4. GitHub Desktop에서 변경사항을 커밋하고 GitHub로 게시합니다.
5. 저장소 Settings → Pages에서 배포 대상을 `main` 브랜치와 `/ (root)`로 지정하고 저장합니다.
6. Pages가 표시하는 주소를 휴대폰 Chrome에서 열어 확인합니다.

`index.html`은 85MB 정도입니다. GitHub 웹페이지에서 파일을 직접 업로드하기보다 GitHub Desktop을 사용하는 편이 좋습니다.

## 현재 버전 안내

- 3D 모델은 HTML 파일 안에 포함되어 있습니다.
- 3D 엔진과 일부 글꼴을 불러오려면 인터넷 연결이 필요합니다.
- 카드 기록과 숲 배치는 현재 사용 중인 브라우저에 저장됩니다. 다른 기기와 자동으로 동기화되지는 않습니다.
- 이 버전에는 아직 설치형 PWA용 매니페스트와 오프라인 지원이 포함되어 있지 않습니다.
